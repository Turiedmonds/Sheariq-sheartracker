Day Configuration Help

What this panel is for

The Day Configuration Panel sets the basic details for the session and run. These settings help the app calculate run time, targets, day clock, and record-specific alerts.

Session Details

Session Date:
The date for this session.

Farm:
The farm/station name for this session. The dropdown helps reuse saved farm names.

Run Setup

Time System:
Sets the run structure used by the app.

Record type:
Use Normal day when no record rules are needed. Strong wool lambs and Strong wool ewes turn on record-specific pen refill rules.

Day Start Time:
Sets the working day start time. The Day Clock is based on this.

Custom Hours:
Used when the time system needs a custom run length.

Target Sheep:
The target number of sheep for the run/day. This is used by Target / Pace calculations.

Sheep Log Help

What this panel shows

The Sheep Log records each sheep when the motor turns ON and OFF.

It shows:

  • Sheep number
  • Start time
  • End time
  • Catch Duration
  • Shear Duration
  • Total Time Per Sheep
  • Marker / Note

Official count adjustments

Rejects are entered from the Performance Panel as an official count adjustment, not tied to a numbered sheep row.

Judges/referees usually report how many sheep were rejected from a judged group or period, while physical sheep remain in this log because they still happened.

Duration columns

Shear Duration:
How long the motor was running for that sheep.

Catch Duration:
How long it took from the end of one sheep to the start of the next sheep.

Total Time Per Sheep:
The total time per sheep. This combines catch time and shear time.

Colour shading

Yellow/orange shading means that time was longer than normal compared with the average for that same column.

Light yellow: Above the normal range, but not more than 2× the average for that column.
Strong yellow: More than 2× the average, but not more than 3× the average for that column.
Orange: More than 3× the average for that column.
  • Normal / no colour: The time is close to the average for that column.

What “average for that column” means:
Each duration column is compared with its own average: Shear Duration with average shear duration, Catch Duration with average catch duration, and Total Time Per Sheep with average Total Time Per Sheep.

Example (catch duration):
If the average catch duration is 7 seconds, 8 or 9 seconds may stay normal, around 12 seconds may show light yellow, around 20 seconds may show strong yellow, and around 25 seconds or more may show orange. This is an example only.

The colour does not automatically mean something went wrong. It is only a quick way to spot times worth checking.

Markers

Automatic marker suggestions stay suggestions until saved. Confirmed markers are user-selected facts from the Marker / Note column, and one sheep can have multiple confirmed markers.

Drink?:
Possible drink break.

Cutter:
Likely cutter change.

Comb:
Likely comb/handpiece change.

A marker appears only when the sheep is near the planned timing window and the catch time is long enough compared with the average catch time per sheep.

Settings

Use the ⚙ button in the Sheep Log header to open Sort, Order, Fill, and Marker Settings.

Planned timing:
How often the planned delay usually happens.

Time window:
How many seconds before or after the planned time the app should check.

Extra seconds over average catch time:
Marker ranges use the current-run average catch time. A marker appears when the catch is at or above the Min seconds over average and below the Max seconds over average. Leave Max blank for open-ended ranges.

Notes

Notes are entered by the user in the Marker / Note column. Use notes to record detail such as a stitch, gear issue, sheep issue, board delay, drink, or cutter change.

Notes alone are for detail only and do not count as markers unless a marker is selected. Automatic markers do not overwrite manual markers or notes.

Sorting

Sorting only changes how the table is displayed. It does not change the sheep numbers or the stored sheep records.

Target / Pace Panel Help

What this panel is for

This panel compares required pace against current run pace and predicts where the run is heading.

Target progress uses the official accepted sheep count: physical sheep minus official reject adjustments. Physical timing averages still use every sheep timed.

Required section

  • Required average total time per sheep: Required Total Time Per Sheep needed to hit the run target.
  • Required 15-minute total: Sheep needed in the current quarter.
  • Required sheep per hour: Hourly pace needed to hit target.
  • Required run total: Target sheep count for this run.
  • Required daily total: Overall daily target.

Predicted section

  • Predicted 15-minute total: Expected total for the current quarter if pace continues.
  • Predicted hour total: Expected hourly total at current pace.
  • Predicted official run total: Expected official run total at current pace. It uses accepted sheep already counted plus physical future pace, and assumes no further rejects until entered.
  • Predicted time to catch target: The predicted time the target-count sheep will be caught/started.
  • Predicted final catch of run: Estimated final catch time before the run ends.
  • Pace difference per sheep: Shows whether pace is ahead or behind and what that means for projected official run total.

Run Target Status section

  • Run target timing: Shows whether the target-count sheep is projected to be caught/started before the end of the run, or missed by a time amount.
  • Current sheep time left: Shows how much time is left on the current sheep before it goes over the required average total time per sheep. Turns red and flashes when over time.

Prediction update behaviour

Predicted values may hold steady while motor is ON and refresh after each sheep is completed, so you can read a stable snapshot during shearing.

Pen refill planning still follows physical sheep movement, not official accepted count.

Timing Panel Help

What this panel is for

The Timing Panel shows what is happening right now during the run. It helps you track the current sheep, run time, quarter timing, and upcoming reminders.

Run badge

Shows the current run number, such as Run 1 or Run 2. During an official break it shows the current break label, such as Morning Smoko or Lunch.

Live sheep timing

Motor state:
Shows the live ON/OFF signal from the Shelly/Evo. ON means the motor is running. OFF means the motor is stopped. The app uses this to start and stop sheep timing.

Current catch time:
Shows how long it has been since the last sheep finished and the next sheep started.

Current shear time:
Shows how long the current sheep has been getting shorn while the motor is ON.

Total time per sheep:
Shows the live running total for the current sheep while it is being shorn, using the current catch time plus the current shear time. Before there is valid timing data it shows —. After a sheep is logged it shows the final Total Time Per Sheep for the last logged sheep.

Green/red Total time per sheep:
Green means the live or final total is under or equal to the required time per sheep. Red means it is over the required time per sheep.

Run timing

Run clock:
Counts forward from the start of the run.

Run countdown:
Counts backward from the run length to zero.

Day clock:
Shows the simulated working day time based on the Day Start Time setting.

Break status / started / remaining:
During an official prepared break, shows that the app is on official break, when the break started, and the remaining break countdown when the selected day type has a known break length.

Next run / next run starts:
During an official prepared break, shows the upcoming run and its scheduled start time when available.

Quarter tracking

Quarter:
Shows which 15-minute block of the run you are in.

For a 2-hour run, there are 8 quarters.

Quarter clock:
Shows how far through the current 15-minute quarter you are.

Alerts

Alerts help you see what is coming up. They are reminders only. They do not mean the shearer must act at that exact second.

Timing alert:
Shows planned timing reminders such as drink break, cutter change, comb/handpiece change, or last quarter.

  • Drink: blue
  • Cutter change: purple
  • Comb/handpiece change: indigo
  • Last quarter: slate/grey

Timing alert uses the Planned timing values from Sheep Log → Marker Settings for Drink, Cutter change, and Comb/handpiece change.

If you change Drink planned timing in Marker Settings, the Timing Panel drink alert will follow that timing too.

Pen refill

Pen refill only applies when a record type is selected in Day Configuration.

If Record type is Normal day / No record rules, Pen refill stays off.

Strong wool lambs:
Pen starts with 20 sheep. Refill is allowed when 5 sheep are left. That means the alert is based on every 15 sheep taken from the pen.

Strong wool ewes:
Pen starts with 10 sheep. Refill is allowed when 2 sheep are left. That means the alert is based on every 8 sheep taken from the pen.

The app counts sheep taken from the pen, not only sheep fully completed. If a sheep is currently on the board being shorn, it counts as taken from the pen.

Pen refill:
Shows the quick live refill alert: 2 sheep away, 1 sheep away, or refill allowed now.

Detailed refill forecast, reminder, strategy, pen state, and refill confirmation status now live in the Pen Refill Planner panel.

Pen refill uses pink so it is separate from the other Timing alert colours.

Pen Refill Planner Help

What this panel shows

The Pen Refill Planner keeps the refill forecast and pen-state details separate from the live Timing Panel alert.

Pen state:
Shows pen count, refill status, last confirmed refill, and the assumed maximum refill amount.

Average refill interval:
Shows the average time between confirmed pen refills.

Recent refill spacing:
Shows the last few confirmed refill intervals.

Next refill:
Shows the next projected refill sheep, minutes from now, and an approximate clock time when available.

Refill status:
Shows where the current pen state sits, including whether a refill is allowed now or still upcoming.

Final refill forecast:
Shows the last projected refill before the run ends and whether it is early, on target, or late.

Strategy:
Shows whether to keep full refills or use a smaller recommended refill.

Confirmation:
Only appears when a smaller-than-full refill needs confirmation.

Performance Panel Help

What this panel is for

The Performance Panel shows the current run performance. It helps you see sheep counts, average times, sheep per hour, and the fastest, slowest, and latest sheep times.

Sheep Count

Total Sheep Shorn:
Shows the physical day count: every sheep fully completed today.

Current Sheep Number:
Shows the sheep number currently being worked through. This may be one ahead of completed sheep when a sheep is on the board.

Official Count:
Shows the official accepted day count. Official Count = physical Total Sheep Shorn minus official rejects.

Rejects:
Shows the official rejected adjustment count. Judges/referees usually report the number rejected from a judged group or period; rejects are not tied to numbered Sheep Log rows.

Physical sheep stay in the Sheep Log and timing history because they still happened. The Pen Refill Planner still uses physical sheep movement.

Quality:
Shows the latest quality rating entered from the judges/referees or liaison, usually by period. Lower quality rating is better.

Averages

Average shear time:
The average time spent shearing each completed sheep.

Average catch time:
The average time between finishing one sheep and starting the next sheep.

Average Total Time Per Sheep:
The average full cycle time per sheep. This includes catch time plus shear time.

Sheep per hour:
The current average number of sheep being completed per hour.

Secondary averages

Secondary averages show average catch times for common marker events.

Drink average: average catch duration when a Drink marker is recorded.

Cutter change average: average catch duration when a Cutter marker is recorded.

Comb/handpiece change average: average catch duration when a Comb marker is recorded.

Custom markers are still tracked in the log and Run Review, but are not shown here because they can mean different things.

Average Total Time Per Sheep colour

The Total Time Per Sheep value may show a coloured outline or background.

The colour helps show whether the average full cycle time is on pace, close to target, or falling behind.

Sheep Times

Last catch time:
Catch/transition time for the most recently completed sheep.

Last shear time:
Shearing time for the most recently completed sheep.

Last total sheep time:
Catch time plus shear time (full cycle) for the most recently completed sheep.

The sheep number in brackets shows which sheep each value belongs to.

Last total sheep time may highlight green/red based on pace against required average total time per sheep.

Fastest sheep today:
The quickest completed sheep so far.

Slowest sheep today:
The slowest completed sheep so far.

Section layout

Each section can be collapsed with the +/− button.

Use the ↑ and ↓ buttons to move sections into the order you prefer.

The app remembers your section order and collapsed sections after reload.

Simulation Controls Help

What this panel is for

The Simulation Controls panel is used to start, stop, pause, and test a run. It also shows simulation controls, autosave controls, manual save controls, shortcut settings, Shelly connection status, and run status.

Simulation Mode

Use Simulation Mode when testing the app without the real Evo/Shelly signal.

Simulation run length lets you test the app with a short run such as 5, 10, or 15 minutes. It only works in Simulation Mode and resets to Real run when Simulation Mode is turned off.

When Simulation Mode is ON:

  • Shelly polling is paused.
  • Motor ON and Motor OFF buttons are shown.
  • Motor shortcuts can be used.

When Simulation Mode is OFF:

  • Motor state should come from the real Evo/Shelly signal.
  • Motor ON/OFF shortcuts do not force the motor state.

Motor ON / Motor OFF

Motor ON simulates the Evo motor starting. Motor OFF simulates the Evo motor stopping.

These buttons are for testing only. In real use, the app should read the motor state from the Shelly inside the Evo.

Run Controls

Start Run: Starts the current run timer.

Stop Run: Stops the current run.

Pause: Pauses or resumes the run timer.

Reset Run: Clears the current run back to its starting state.

Finish Run / Break: Ends the run and opens the official break banner. If the scheduled run time has not finished yet, the app asks you to confirm before starting the break early.

Disabled buttons

Some buttons become unavailable depending on the run state. For example, Stop Run is unavailable before a run starts. A disabled button means the app is preventing that action at that moment.

AUTOSAVE

Autosave runs automatically in the background.

It saves your current session at a time interval chosen by you.

Autosave is designed as a safety feature in case:

  • browser crash
  • accidental refresh
  • accidental tab closure
  • unexpected interruption

Use Load Last Autosave to restore the most recent automatic save.

Only the latest autosave is kept.

Each autosave overwrites the previous autosave for that session date.

MANUAL SAVE

Manual saves are user-created checkpoints.

Use Save Session to create a named checkpoint at any time.

Manual saves are useful when:

  • testing against recorded livestreams
  • pausing work and returning later
  • creating multiple restore points

Use Load Session to choose and restore a specific manual save.

Manual saves do not replace autosaves.

Status

Shelly status: Shows whether the app can talk to the Shelly helper/proxy and how long the response took.

Run Status: Shows whether the run is idle, running, paused, or stopped.

Shortcut Settings

The gear button in the panel header opens Keyboard Shortcut Settings.

You can set your own shortcut keys for Start Run, Stop Run, Pause / Resume, Reset Run, Finish Run / Break, Motor ON, and Motor OFF.

Shortcuts do not run while typing in fields.

The Finish Run / Break shortcut follows the same early-break confirmation as the button.

Motor ON/OFF shortcuts only work when Simulation Mode is ON.

Section layout

Each section can be collapsed with the +/− button.

Use the ↑ and ↓ buttons to move sections into the order you prefer.

The app remembers your section order and collapsed sections after reload.
